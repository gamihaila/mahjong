#
# Format (one hand per line):
#   <groups...> :: <note>
#   Groups are separated by spaces. Each group carries the color it
#   is printed in, as a one-letter prefix: b = blue, g = green,
#   r = red. Same prefix within a hand = same suit. Flowers (F) and
#   winds (N/E/S/W) have no suit; their prefixes carry no suit
#   meaning. Digits are tile ranks; 0 is the soap (white dragon)
#   used as zero. D = a dragon of the suit its color indicates.
#   Every hand must total 14 tiles; in this notation each character
#   of a group is one tile (e.g. NEWS = 4, 113579 = 6, 1D = 2).
#   Tile counts were machine-validated: all 72 hands total 14.
#   Notes state the suit/count constraints as the guide prints them.
