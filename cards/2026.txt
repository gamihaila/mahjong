# Format (one hand per line):
#   <X|C><points> <groups...> :: <note, verbatim from the tracker>
#   X = exposed hand allowed, C = concealed hand only.
#   Groups are separated by spaces, exactly as printed.
#   Each group carries the color it is printed in, as a one-letter
#   prefix: b = blue, g = green, r = red. Same prefix within a hand =
#   same suit. Flowers (F) and winds (N/E/S/W) have no suit; their
#   prefixes are transcribed as printed but carry no suit meaning.
#   Digits are tile ranks as printed; 0 is the soap (white dragon)
#   used as zero. D = a dragon of the suit its color indicates.
#   Every hand must total 14 tiles; in this notation each character
#   of a group is one tile (e.g. NEWS = 4, 113579 = 6, 1D = 2).
#   Tile counts were machine-validated after transcription: all 72
#   hands below total 14. Color prefixes were read from a photograph
#   and are the most error-prone part.
#   Provisional ruling (George, 2026-11-04): on three hands the photo
#   showed three colors while the note said "Any 2 Suits"; the note
#   won — the third color was folded into the second suit. Those
#   hands: FF 2222 44 66 8888 (2468); 1111 D 111 D 1111 D (Any Like
#   Numbers); 1111 33 55 77 9999 (13579). The official card, when it
#   arrives, supersedes this whole file.
